# Portable research snapshots

These files are selected snapshots of the live Markdown research under `/notes/`.
Snapshot date: October 30, 2026.
The export rewrites local links and includes the referenced camera-interface images.

The research contains proposals and historical decisions. It is not additional implementation scope.
Use [the first native specification](../specs/0002-first-native-mvp.md) for current requirements.

To refresh the snapshots on the original research host, run `python3 scripts/sync-research.py` from the project root.
Receiving developers do not need `/notes/` to build or read this handoff.
Future research should still be recorded under `/notes/` according to the project instructions.
